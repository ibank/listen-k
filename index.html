전사 엔진 준비 중
WhisperKit 모델을 Core ML 로 컴파일하고 있습니다. 재설치 직후에는 30~90초 걸릴 수 있고, 이후엔 캐시되어 수 초 내에 준비됩니다.
경과: 0초

설정 상태

엔진

전사 엔진
Apple Speech 는 빠르고 경량, WhisperKit 은 정확, whisper.cpp 는 배치 전용.
전사 모델
큰 모델일수록 정확하지만 느립니다. 자동은 품질 우선으로 선택됩니다.
OpenAI API 키
platform.openai.com/api-keys 에서 발급. macOS Keychain 으로 암호화 저장됩니다. OPENAI_API_KEY 환경변수가 있으면 그게 우선 적용됩니다.
OpenAI 모델
gpt-4o-transcribe 가 품질 최상 ($0.006/분). mini 는 절반 가격·중간 품질. whisper-1 은 구세대 호환용.

단축키 & 입력

단축키
전역에서 녹음을 시작·중지하는 키. 더블탭은 380ms 이내.
언어
Whisper 전사 언어 힌트. Apple Speech 는 locale 로 바꿔 적용됩니다.
실시간 표시
HUD 에 말하는 동안 텍스트를 흘릴지. 끄면 완료 후에만 표시.

후처리

후처리 모드
전사 결과를 정제 / 번역 / 원문 그대로 중 선택.
번역 대상 언어
전사된 텍스트를 이 언어로 번역합니다.
Ollama 모델
설치된 모델 중 선택. 다른 터미널에서 ollama pull 하면 자동 갱신.
톤
Ollama 정제 시 적용되는 문체.

사용법

1 텍스트를 입력할 곳에 커서를 둡니다.
2 ⇧⇧ 한 번 — 녹음 시작 (HUD 표시).
3 말을 마치면 다시 ⇧⇧ 또는 HUD 의 ✓.
4 정제·번역된 텍스트가 포커스된 필드에 자동 붙여넣어집니다.
