Apple Speech is fast and lightweight, WhisperKit is accurate, whisper.cpp is batch-only.
Transcription model
Larger models are more accurate but slower. "Auto" picks the best installed.
OpenAI API key
Get one at platform.openai.com/api-keys. Stored encrypted via macOS Keychain. OPENAI_API_KEY env var takes precedence.
OpenAI model

Usage

1 Put the cursor where you want text.
2 ⇧⇧ once — recording starts (HUD appears).
3 When done speaking, ⇧⇧ again or click ✓ on the HUD.
4 The cleaned/translated text is auto-pasted into the focused field.
Cancel via ✕ on the HUD · alternate hotkey ⌘⇧Space
